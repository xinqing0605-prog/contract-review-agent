## 已知限制汇总

1. **SQLite 单实例**：多副本部署需换 Postgres
2. **扫描版 PDF 无 OCR**：解析为空会给出明确提示
3. **规则检测召回有限**：同义改写（如"单方解除且无需补偿"）会漏
4. **全局单一"当前模型"**：不能按对话/文档选模型
5. **无团队空间**：数据严格按个人隔离
