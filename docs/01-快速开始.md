# 01 · 快速开始

## 环境要求

| 依赖 | 版本 | 说明 |
| --- | --- | --- |
| Python | 3.10+ | 后端与脚本 |
| Node.js | 18+ | 仅构建前端时需要 |
| PowerShell | 5.1+ | 启动脚本 |
| 操作系统 | Windows 10/11、macOS、Linux | 脚本为 PowerShell，其他系统可按命令手动执行 |

## 启动（推荐）

```powershell
cd F:\contract-review-agent
.\start_all.ps1 -Open
```

- `-Open` 会自动打开浏览器
- 首次运行会自动创建 `.venv` 并安装后端依赖
- 启动完成后：

| 地址 | 用途 |
| --- | --- |
| http://127.0.0.1:8103 | 应用主界面 |
| http://127.0.0.1:8103/docs | FastAPI 自动生成的接口文档 |

## 停止

```powershell
.\start_all.ps1 -Stop
```

## 前端开发模式（可选）

改前端需要热更新时，两个终端分别跑：

```powershell
# 终端 1：后端
.\run_local.ps1

# 终端 2：前端（http://127.0.0.1:5173，/api 已代理到 8103）
cd web
npm run dev
```

改完前端后要刷新 8103 的页面，需要重新构建：

```powershell
cd web
npm run build
```

## 端口冲突

`start_all.ps1` 启动前会自动结束占用 8103 / 5173 的进程。如果仍失败：

```powershell
Get-NetTCPConnection -LocalPort 8103 -State Listen
Stop-Process -Id <PID> -Force
```

## 依赖安装

前端依赖需要自行安装一次，并构建产物（后端同源托管 `web/dist`）：

```bash
cd web
npm install
npm run build
```

## 目录速览

```
backend/   后端：接口、规则检测、模型调用、文件解析
web/       前端：React + TS + Vite
eval/      评测：标注集、指标、评测脚本
tests/     测试：接口与租户隔离、冒烟
docs/      文档（本目录）
data/      运行时数据：上传的原始文件、密钥文件（自动生成，勿提交）
```
