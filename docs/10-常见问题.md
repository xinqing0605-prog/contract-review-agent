# 10 · 常见问题

## 启动类

**Q：`start_all.ps1` 闪一下就没了**
用 PowerShell 直接执行看报错：

```powershell
powershell -ExecutionPolicy Bypass -File .\start_all.ps1
```

常见原因：`.venv` 缺失、端口被占、PowerShell 执行策略限制。

**Q：提示端口被占用**
脚本会先尝试结束占用 8103/5173 的进程；仍失败就手动：

```powershell
Get-NetTCPConnection -LocalPort 8103 -State Listen
Stop-Process -Id <PID> -Force
```

**Q：页面白屏**
F12 看 Console。多半是 `web/dist` 没构建：

```powershell
cd web; npm run build
```

**Q：接口返回 401，但我已经登录了**
Cookie 没带上或已过期（7 天）。清 Cookie 重新登录。跨域部署时前端必须同源或带 `credentials`。

## 模型类

**Q：测试连接提示"Key 无效或已失效"**
Key 与服务商不匹配，或地址填错（常见：DeepSeek 不需要 `/v1`，OpenAI 需要 `/v1`）。

**Q：提示"服务商地址变了，请重新填写 API Key"**
安全设计：Key 与地址绑定，换地址必须重输 Key，防止把旧 Key 发到新主机。

**Q：提示"该地址解析到内网，已拒绝"**
SSRF 防护。本地 Ollama 需要服务端设 `CLAUSEGUARD_ALLOW_PRIVATE_MODEL=1`。

**Q：模型超时**
默认 90 秒。合同太长或模型太慢，可换更快的模型，或先缩小合同。

**Q：审阅显示"未配置模型，使用规则解释"**
没有勾选「当前使用」的模型。去模型设置里点「设为当前」。

## 审阅类

**Q：高亮位置错位**
`start_offset/end_offset` 与正文不一致。自检：

```powershell
$t = Invoke-RestMethod "http://127.0.0.1:8103/api/documents/contract-01/text"
$d = Invoke-RestMethod "http://127.0.0.1:8103/api/documents"
$c = $d[0].clauses[0]
$t.text.Substring($c.start_offset, $c.end_offset - $c.start_offset) -eq $c.original
```

应为 `True`。

**Q：条款漏检**
规则只认关键词。比如"单方解除且无需补偿"没有关键词命中。这是已知局限，评测集里有对应用例。

**Q：重复审阅后批注没了**
按条款类型保留；如果条款类型变了（规则调整），旧批注会丢失。当前按 `title` 匹配。

## 文件类

**Q：PDF 导入后是空的**
扫描版没有文字层。需要 OCR（未实现），或先用其他工具转成文本。

**Q：Word 里的表格没解析到**
已支持表格，会以 `[表格]` 标记开头、每行用 ` | ` 分隔单元格；
合并单元格会退化成重复文本，需要人工核对。

**Q：PDF 里的表格和图片怎么办**
- **表格**：只能读到文字，列结构会塌缩成一行，需要人工辨认
- **图片**：不解析图片内容；图片里的文字属于扫描件，需要先 OCR

建议：同一份合同如果同时有 docx 和 pdf，**优先导入 docx**——段落、表格结构都更完整。

**Q：导入后文字全挤在一起**
v14 起已修：前端保留换行，PDF 抽取后按句末标点重排段落。
如果仍挤在一起，确认用的是最新构建（`cd web; npm run build`）。

**Q：导入报 413**
解析后超过 30 万字符。拆分合同或调大 `MAX_TEXT_CHARS`（需改代码）。

## 数据类

**Q：换了机器，模型 Key 全失效**
`data/.master.key` 没跟过来。恢复该文件，或改用固定的 `CLAUSEGUARD_SECRET`。

**Q：怎么彻底删掉一个账号的数据**
目前没有自助注销。手动删库：

```sql
DELETE FROM clauses WHERE document_id IN (SELECT id FROM documents WHERE user_id='user-xxx');
DELETE FROM review_audit WHERE user_id='user-xxx';
DELETE FROM documents WHERE user_id='user-xxx';
DELETE FROM service_models WHERE user_id='user-xxx';
DELETE FROM model_services WHERE user_id='user-xxx';
DELETE FROM service_presets WHERE user_id='user-xxx';
DELETE FROM sessions WHERE user_id='user-xxx';
DELETE FROM users WHERE id='user-xxx';
```

**Q：数据库文件能直接拷走吗**
可以，但要连 `data/.master.key` 一起拷，否则 Key 解不开。

## 前端类

**Q：改了代码页面没变**
8103 提供的是构建产物：

```powershell
cd web; npm run build
```

然后 Ctrl+Shift+R 硬刷新。开发时用 5173（`npm run dev`）可热更新。

**Q：弹窗滚不动**
已在 v9 修成固定高度 + 内部滚动；如果仍是整页滚动，检查浏览器是否 ≥1280px（`xl` 断点才启用应用外壳）。
