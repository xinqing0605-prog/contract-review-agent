# 13 · 部署到云端（无需本地安装）

本仓库自带 `Dockerfile`：前端在构建阶段打包，后端在运行阶段同源托管，**一个容器一个端口**。

适用于任何支持 Docker 或能从 GitHub 自动构建的平台：Render、Railway、Zeabur、Koyeb、Hugging Face Spaces 等。

## 部署前必须知道的三件事

1. **数据在磁盘上**
   SQLite 数据库 + 上传的合同 + 加密主密钥都在 `CLAUSEGUARD_DATA`（默认 `/data`）。
   平台如果不给持久磁盘，**重启或重新部署后数据会清空**。

2. **只能单实例**
   SQLite 不支持多副本并发写，不要开横向扩容。

3. **必须配 HTTPS**
   Cookie 的 `secure` 标记和登录态依赖 HTTPS，平台默认提供的域名一般自带证书。

## 环境变量

| 变量 | 建议值 | 说明 |
| --- | --- | --- |
| `CLAUSEGUARD_SECRET` | 随机长字符串 | 加密模型 Key 的主密钥。**必须固定**，换了已存 Key 全部失效 |
| `CLAUSEGUARD_SECURE_COOKIES` | `1` | 只允许 HTTPS 传输 Cookie |
| `CLAUSEGUARD_ALLOW_PRIVATE_MODEL` | `0` | 禁止用户把模型地址指向内网（防 SSRF） |
| `CLAUSEGUARD_DATA` | `/data` | 数据目录，需要挂持久盘 |

生成随机密钥（本机 PowerShell 执行，不安装任何东西）：

```powershell
-join ((48..57) + (65..90) + (97..122) | Get-Random -Count 48 | ForEach-Object { [char]$_ })
```

## Render 部署步骤

1. 登录 https://render.com ，用 GitHub 账号授权
2. 右上 **New +** → **Web Service** → 选择 `contract-review-agent` 仓库
3. 配置：
   - **Language**：`Docker`（会自动识别根目录 `Dockerfile`）
   - **Region**：`Singapore`（离国内近）
   - **Instance Type**：先用 `Free`
4. 展开 **Environment Variables**，添加上面三个变量
5. 点 **Create Web Service**，等 5–10 分钟构建

构建完成会得到一个 `https://xxx.onrender.com` 地址，打开就是完整应用。

### 免费档的限制

- 15 分钟无访问会休眠，下次打开要等约 30 秒冷启动
- **没有持久磁盘**，重新部署或重启后数据库清空（用来收集反馈够用）
- 升级到 Starter（约 $7/月）后可挂 1GB 磁盘，把挂载路径设为 `/data`

## 验收清单

部署完成后逐项确认：

- [ ] 打开首页能看到登录界面
- [ ] 用 `demo@clauseguard.local / demo1234` 能登录
- [ ] 模型设置里添加一个服务商和模型，测试连接成功
- [ ] 上传一份合同，运行审阅能看到流式步骤
- [ ] 刷新页面后合同还在（说明磁盘持久化生效）
- [ ] 换一个浏览器注册新账号，看不到前一个账号的合同

最后一条最重要——**数据隔离是公开演示的底线**。

## 公开演示的注意事项

1. **注册是开放的**：任何人都能建账号。每个账号数据隔离，不会互相看到
2. **模型费用由用户自己承担**：每个账号填自己的 API Key，你不需要为别人的调用付费
3. **磁盘可能被占用**：单文件上限 8 MB，建议定期清理 `data/uploads` 与数据库
4. **演示账号密码是公开的**：`demo1234` 出现在 README 里，不要在里面存放真实合同
5. **没有邀请码机制**：如果需要限制访问，后续可以加一个注册邀请码
