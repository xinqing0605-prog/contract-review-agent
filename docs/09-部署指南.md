# 09 · 部署指南

## 形态一：单机（推荐起步）

后端同时提供 API 与前端静态资源，**只需要一个进程、一个端口**。

```powershell
cd F:\contract-review-agent
.\start_all.ps1
```

### 开机自启（Windows）

用「任务计划程序」创建任务：

- 触发器：登录时
- 操作：`powershell.exe -NoProfile -ExecutionPolicy Bypass -File "F:\contract-review-agent\run_local.ps1"`
- 起始于：`F:\contract-review-agent`

### Linux / macOS

```bash
python3 -m venv .venv
.venv/bin/pip install -r backend/requirements.txt
.venv/bin/python -m uvicorn backend.app:app --host 127.0.0.1 --port 8103
```

systemd 示例：

```ini
[Unit]
Description=ClauseGuard
After=network.target

[Service]
WorkingDirectory=/opt/clauseguard
ExecStart=/opt/clauseguard/.venv/bin/python -m uvicorn backend.app:app --host 127.0.0.1 --port 8103
Restart=always
Environment=CLAUSEGUARD_SECRET=换成你的固定密钥
Environment=CLAUSEGUARD_SECURE_COOKIES=1
Environment=CLAUSEGUARD_ALLOW_PRIVATE_MODEL=0

[Install]
WantedBy=multi-user.target
```

## 形态二：Docker

```dockerfile
FROM node:20-slim AS web
WORKDIR /app/web
COPY web/package.json web/package-lock.json* ./
RUN npm install
COPY web/ ./
RUN npm run build

FROM python:3.12-slim
WORKDIR /app
COPY backend/requirements.txt backend/
RUN pip install --no-cache-dir -r backend/requirements.txt
COPY backend/ backend/
COPY --from=web /app/web/dist web/dist
ENV CLAUSEGUARD_DATA=/data
VOLUME ["/data"]
EXPOSE 8103
CMD ["python", "-m", "uvicorn", "backend.app:app", "--host", "0.0.0.0", "--port", "8103"]
```

```bash
docker build -t clauseguard .
docker run -d -p 8103:8103 \
  -e CLAUSEGUARD_SECRET=your-secret \
  -e CLAUSEGUARD_SECURE_COOKIES=1 \
  -e CLAUSEGUARD_ALLOW_PRIVATE_MODEL=0 \
  -v clauseguard-data:/data \
  clauseguard
```

> 仓库未内置 Dockerfile，直接使用上面的示例即可（路径结构与本仓库一致）。

## 环境变量

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `CLAUSEGUARD_DB` | `backend/clauseguard.sqlite3` | 数据库路径 |
| `CLAUSEGUARD_DATA` | `./data` | 上传文件与主密钥目录 |
| `CLAUSEGUARD_SECRET` | 无 | 加密主密钥来源；不设置则用 `data/.master.key` |
| `CLAUSEGUARD_SECURE_COOKIES` | `0` | `1` 表示 Cookie 只走 HTTPS（生产必须） |
| `CLAUSEGUARD_ALLOW_PRIVATE_MODEL` | `1` | `0` 禁止模型地址指向内网（公网部署必须） |

## 反向代理（Nginx）

```nginx
server {
    listen 443 ssl http2;
    server_name clause.example.com;

    ssl_certificate     /etc/ssl/fullchain.pem;
    ssl_certificate_key /etc/ssl/privkey.pem;

    client_max_body_size 10m;

    location / {
        proxy_pass http://127.0.0.1:8103;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-Proto $scheme;

        # SSE 必须关闭缓冲，否则步骤会攒到最后一起吐
        proxy_buffering off;
        proxy_read_timeout 300s;
    }
}
```

**SSE 关键点**：`proxy_buffering off`，代码里也已设置 `X-Accel-Buffering: no`。

## 备份与恢复

```powershell
# 备份
Copy-Item backend\clauseguard.sqlite3  backup\
Copy-Item data                          backup\data -Recurse

# 恢复：停服务 → 覆盖文件 → 启服务
```

**必须同时备份 `data/.master.key`**（或固定 `CLAUSEGUARD_SECRET`），否则已保存的模型 Key 无法解密。

## 升级流程

1. 备份数据库与 `data/`
2. 拉取新代码
3. `cd web; npm install; npm run build`
4. `.venv\Scripts\python.exe -m pip install -r backend\requirements.txt`
5. 重启服务 —— 迁移在启动时自动执行
